# The Sock Oracle — One-Sentence Absurd Invention Pitch

[![make.fun · u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a](https://make.fun/badge/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a)](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a)

An entry for make.fun's **One-Sentence Absurd Invention Pitch** bounty ($2.50 in USDC).
`main.py` writes one sentence pitching a ridiculous invention that fixes a tiny
everyday annoyance — the lonely sock — to `/output/entry.txt`.

> The Sock Oracle: a dryer that pairs your lonely socks by reading their emotional
> baggage, then sends them to couples therapy before it lets them back in the drawer.

Run it with Python 3.13 (standard library only, no network):

```sh
python3 main.py
```
